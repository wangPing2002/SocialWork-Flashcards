# 第七轮：PPT首段专业定义与得分点覆盖率初审（V2.9.0六轮基线）

## 审查来源与顺序

1. 《东南大学——院校分析与真题解读(2).pptx》第12、15—17页：名词解释为“领域—定义—多维补充”，简答题“总—分—总”并在首段进行相关概念解释。
2. 《王思斌〈社会工作概论〉（第4版）笔记和课后习题（含考研真题）详解》272页PDF：以对应章节的课后习题与真题详解作为概念与得分点来源。此轮所改30张全部在逐卡清单注明参考页码，但**不是声称30题都与王思斌原题一一对应**。
3. 其余题目参考原有教材来源，严禁因书籍主题相近就移植整篇答案。本轮未改无直接依据的实务题。

## 本轮已完成

- 扫描基线：2497张卡，其中简答题1784张、名词解释234张、论述题252张、案例分析题188张、材料题39张。
- 此前六轮已有95张答案精修记录；本轮只选**未修改的简答题**，修改**30张**，累计不同卡片答案精修记录为125张。
- 其中 **28张**调整简答题首段术语界定和进入分点的过渡，原有一级得分点不变；**2张**（C0086、C0090）按王思斌详解明确分类重组一级得分点与展开，删除偏离题干的通用伦理段落。
- 新增《README.md》首段定义和分点审查标准；新增逐卡修订记录 CSV 与全库待审核候选 CSV。
- 修订卡片完整答案均在500—700字，保留高亮颜色 `#C62828`，不改变快记、关联、考频等元信息字段。

## 客观扫描与核查边界

- 规则扫描能够识别“未包含明显定义句”“首段反复使用同一套模板”“措施题未识别具体技巧用语”等，但**不能证明所有命中都是知识错误**。
- 自动优先级候选：762张（高 221、中 388、低 153）。仅是下一轮人工审查的优先排序，不代表已按资料逐张核实或全部需要替换。
- 例如：同一个“家庭社会工作”首段可能被复用于若干不同具体问题（夫妻关系、评估方式、危机介入等）。即使领域定义本身正确，也可能因未解释题干具体概念而影响针对性。
- 本轮尚未逐题核实所有剩余卡的一级得分点覆盖率，也不能给出虚构的全库得分率百分比。下一批对高优先级候选重点核对“题干关键词—源书得分点—现有一级得分点”三列。
- 对无直接支持的题保留，不以字数达标、模式统一为目的发明材料。

## 后续优先级建议

1. **高：** 模板性空话、具体题干却直接重复领域定义的卡，先查看《王思斌》是否存在相应具体概念；无则回四本核心教材。
2. **中：** 首段模糊但原分点有效的卡，优先以原答案内已有准确论述前移组织，不增加无证据内容。
3. **专门复核：** 论述/案例的“事实识别—理论依据—措施—预期结果”，不能只看分点数量或词汇频率。

## 补丁使用

基于已应用**六轮合并/增量补丁**的 V2.9.0 工程，应用 `v2.9.0_round7_after_six_rounds.patch`，补丁文件放在 `E:\Download`（项目外）。先 `git apply --check` 再应用，随后执行 `python scripts/sync_master_answers.py --review-batch intro_definitions_2026_10` 只将30张修订同步至 Markdown 母版；重复同步应为0改动。**不要直接进行无筛选的全量同步**：六轮基线的 C2111 母版有预先存在的第三版本文本，既不等于修改前的原始答案，也不等于当前 cards.json。它不在本轮修改范围，不能自动覆盖。

## 发布限制

本轮只是题库内容与静态一致性校核，**未执行 GitHub Actions APK 编译、未测试实机**；不修改已发布的 `v2.9.0` tag。如决定发布更新，应另行升版本和走 Actions 验证。
