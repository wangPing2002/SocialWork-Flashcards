# V2.9.0 主观题分题型答案审校规范（第十轮补充）

> 核对依据：东南大学《院校分析与真题解读》PPT 第12、15—17页；王思斌《社会工作概论》第4版笔记与习题详解；现有东南大学 MSW 参考高分答案示范。后两类资料不是学校官方评分细则。**题型先于字数**，但字数不应凌驾于知识真实性和得分点完整性。

| 题型 | 正确结构 | 特别注意 | 既定训练字数（非学校官方硬性标准） |
|---|---|---|---|
| 名词解释 | 所属范畴 → 一句话精准定义 → 最关键特征/构成/边界 → 必要关联 | 核心是定义准确、范畴清楚；**不套用简答题的五个分点，更不能拉长成论述文** | 250—300字 |
| 简答题 | 首段相关专业术语名词解释，回应题干范围 → 按题干列完整一级得分点并解释 → 简要、紧扣题干总结 | 比较题开头需分别界定双方；问“方法”要有实际方法，问“原则”不能只列操作措施；不要用领域介绍充当定义 | 500—700字 |
| 论述题 | 明确论题、概念与理论观点 → 围绕问题展开分层论证（机制、因果、辩证分析）→ 适当举证、局限/评价、社工关联 → 总结 | **不能压缩成简答题的若干分点**，需要有解释力度、联系和评价；不添加无依据的宏观口号 | 原约约900字；以论证完整为准 |
| 案例分析题 | 按材料及小问逐问作答 → 情境与需求/风险评估 → 理论选择与目标 → 分层介入、明确主体、方法、步骤和资源 → 伦理、评估与跟进 | 不编造材料中没有的事实；“怎么做”要说谁来做、对谁做、怎样做、如何评价；**不用单纯理论综述替代个案介入** | 原约约900字；随小问分配篇幅 |
| 材料题 | 先识别材料中的问题与问法 → 每个小问单独回应 → 必要概念/机制/证据/操作方案 → 总结 | 不假定材料题必定等于案例服务计划；政策评析、比较、方案设计等须依题干选择论证路径 | 原约约900字；按小问与分值分配 |

## 修改判定

- P0：概念定义错误；题型格式串用；主要论点答非所问；实务题方法无操作性或有明显伦理风险。优先修复。
- P1：缺少有教材依据的一级得分点；定义过于泛化；结尾只重复最后一个得分点；分层措施不完整。核实后修复。
- P2：重复或轻微冗长；字数略超界/不足界但得分点充分。仅在提升准确性与可背诵性时修改。
- **不允许**：为达到字数机械堆砌“增强社会支持、促进社会融入”等；将《社会工作概论》一般论述生搬硬套为信访、新就业、司法实务专门得分点；引用没有核对的页码冒充已经审实。
- 高亮：仅一级得分点或关键判断使用 `#C62828`；解释和例子保持普通文字，保持正常自然段。
- 来源分层：有直接详解优先取高质量得分结构；概论详解无法直接覆盖时回到《社会工作实务-250纠正》和《2026中级综合》相关章节，不编造答案。

## 审核档位与解释

- **结构审校通过**：格式、题型、编号、段落和主题一致；**不代表**教材内容均已核实。
- **教材直接核对**：新增得分描述可定位到对应教材小节和可见页码；需保留核对记录。
- **沿用原有要点**：只改变解释或总结，未逐项审实既有一级得分点。
- **待核实**：暂缺直接依据、或教材只能支撑概念但无法支撑细目。不得标为完整高分标准答案。

## 第十轮范围

对第九轮留下的 66 张篇幅预警、105 张薄弱结尾卡逐题按 `questionType` 核对：这171张**全部属于简答题**，两个集合无重合。17张做有章节依据的实务步骤补强，105张按原有得分点改为针对性结语；其余49张不为凑字数强改。结尾调整不代表原有一级得分点已逐项获得独立教材认证。详见本轮 CSV 审核表和报告。
