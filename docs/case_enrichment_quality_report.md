# V3.0.0 RC1 案例材料质量与证据状态报告

## 处理对象与真正完成的修改

以V3.0.0 RC1的84份案例/176道子问作为只读母版：其中78份原创新编案例主要不足350字符，普遍偏于一句概括现象，不能支持较完整的事实提取与小问论证。本次逐篇增写具体主体、事件经过、利益冲突、原话、风险与优势、政策或机构边界、可用资源和阶段性变化；保留`originalMaterial`和相应SHA-256，支持一键切回原收录材料。 **新增情节全部为原创训练设定，未经事件发生事实核实，不能当作东南大学真题原文。**

- 78份扩写后训练案例：字符长度 **571—758，中位数628.5**；62份至少600字符。强调材料密度和可答性，不为追求字数简单重复。
- 6份历史汇编材料原文：保留`material == originalMaterial`；新补充文字置于`trainingExpansion`，默认仍显示原收录文句。使用者须主动点击带有“非原卷”标识的切换按钮才能查看模拟补充情境。扩写不提升历史真题真实性等级。
- 2份依据公开案例机制改编的原创训练案例：共新增6道完整小问、解析和得分点，分别关联`C0644`、`C2031`。公开案例只说明相关法律与专业工作机制；新案例的时间、角色、对话和材料事实均为虚构训练设定。
- 原84份的**176道小问、全部答案与状态逐字保留**，并在`docs/case_subquestion_176_original_sha256.json`中设独立SHA门禁；2497张母卡与正式答案完全没有修改。

1. 最高人民法院：《最高法发布人民法院反家庭暴力典型案例（第一批）》，2023-11-25，https://www.court.gov.cn/zixun/xiangqing/418562.html 。参考照片、报警记录、求助与保护令的证据判断，以及法律与社工职责分界；**不复刻具体裁判事实**。
2. 最高人民检察院、中央社会工作部：《在未成年人检察工作中加强社会工作服务的典型案例》，2025-05-28，https://www.hnhengdong.jcy.gov.cn/jcyw/202509/t20250918_7144726.shtml 。参考不同法定处遇下司法社工的分级分类干预、家庭教育与社会融入服务机制；**不重述或假装替代真实原案**。

两处来源均已人工打开对照其发布机关、发布日期及可见正文；并不据此认定其他84份材料均有外部现实事件来源。

## 训练材料阅读规范

- 对`原创强化训练案例（非历年原题）`，默认显示完整扩写训练情境；页面支持“只看扩写前收录材料”，不减少原问题和答案信息。
- 对`汇编材料（原卷未核验）`，默认显示收录原句；仅在学习者主动点击后显示带明确来源警示的扩展模拟，不得作为真题原卷全文使用。
- 对`依据官方案例机制改编`，默认显示原创模拟，附官方来源与“仅专业机制可追溯”说明。
- 模拟场景中的人口统计、对话、数额、事件与机构条件属于教学设计变量；凡未获得权威原始证据，绝不使用“实际发生”“原题已核实”“官方标准答案”等标签。
