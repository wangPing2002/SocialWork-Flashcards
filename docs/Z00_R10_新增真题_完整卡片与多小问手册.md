训练分值：6；有效字：160。

**完整解答（不含助记）：**

【概】<span style="color:#C62828">社会福利三分法依福利渠道区分剩余性福利、财政福利与职业福利。</span>
【特】剩余性福利弥补市场和家庭缺口；财政福利通过税收优惠分配利益；职业福利与单位和职业身份相联。

【关】社工应帮助服务对象识别并进入适宜福利渠道。分类有助于分析不同福利供给主体承担的社会责任。

## R10-013｜2020年·437·简答题

**原汇编题文（逐字保留）：**

```text
2. 近几年，社会工作界发展出循证社会工作（证据为本的社会工作），一些社会工作者也遵循循证社会工作来开展服务，引起了一些讨论和争议。请解释循证社会工作，并谈谈你的看法。
```

来源：COMP-2020-437-简答-0117；原题SHA-256：`e9d47d0b31fcb79e9e741c6babd8574f28ecc5128177578767e8fe42d37f1618`。

训练分值：20；有效字：510。

**完整解答（不含助记）：**

【总】<span style="color:#C62828">循证社会工作强调将最佳可获得研究证据、专业判断和服务对象具体处境结合，检验干预方法的效果，而不是单凭经验作决定。</span>
（1）证据使用。在界定问题和形成目标后系统检索可靠研究，辨别方法、样本和结论的适用范围，选择最能回答本案问题的证据。
（2）合作决策。同服务对象商议目标、偏好和可接受风险，把价值判断与证据选择结合，尊重自主权，避免将标准化方案强加于个人。
（3）执行评估。在介入过程中记录服务实施、问题变化和不良后果，兼顾量化指标、访谈及个案追踪，依反馈及时调整计划。
（4）优势价值。循证取向能提高专业服务的科学性、责任性和资源使用效率，促进“实践—研究—再实践”的知识循环。
（5）局限反思。复杂情境难由单一研究完全概括，过分崇拜数字、排除难以量化的经验或忽视文化差异，反会损害服务对象利益。
【扩展】首先，证据质量应结合研究方法、样本和服务情境判断。研究结论在不同人群或地区未必具有同样效果，工作者应考虑服务成本、副作用和文化差异。其次，循证过程要求事先设定可观察的目标，既记录项目实施，也跟踪服务对象实际变化；当证据与本人意愿或现实风险冲突时，应再次协商方案，必要时寻找替代方法。循证的真正价值是提高可检验性与专业责任，而不是用固定模型取代人的选择。
【总】因此，循证不是照搬证据或放弃专业判断，而是以科学研究支持、以服务对象需要为中心、以持续评估保证质量的反思性实践。

**快速记忆：**

答题骨架：总述立论 → 分点解释 → 总结评价
三词：证据判断 · 专业经验 · 服务对象
记忆注解：按“证据判断—专业经验—服务对象”依次复述；仅作检索线索，不能替代完整答案。
