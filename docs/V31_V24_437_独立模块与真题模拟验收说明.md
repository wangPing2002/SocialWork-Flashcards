# 社会工作闪卡 V3.1.0 RC1｜Z00—Z08 + V24 437 独立模块

## 一、项目改动（开发候选、非正式发行）

- **原 C0001—C2497 主库保持2497条**：`app/src/main/assets/cards.json`、`content/master/cards_master_2497.md`、`quick_memory_v3.json`、`case_bank_v30.json`、`exam_meta.json`、`question_overlay_v30.json` 不执行覆盖修改。学习进度继续按 cardId 保存。
- **V24 独立入口**：首页「437 专项独立模块」和卡片库专用入口，使用 `v24_437_378_cards.json` 的 `437M001—437M378`。原原始骨架、五维答案、训练分值、历史分值、三词提示、状态和对应哈希保留，完整版位于 `content/v24_437_module/`。
- **严格禁止 V24进入331组卷**：`CardRepository.eligibleForExam()` 对 `V24_437` 只允许科目437；`MockExamEngine.fill()` 的初选及不足题回退均执行该门禁，且仅向437名词解释池添加 `v24Cards`；不将其当作官方真题。
- **Z00—Z08**：9份上传增量包按来源编号转换为 `z_staging_overlays_v31.json`（每张基线卡按 ID 显式切换原版／多个Z来源候选），未覆盖原2497题；输入归档哈希及冲突统计在 `docs/Z00_Z08_输入档案与互不覆盖统计.json`。在学习卡片「核心答案」中点击「切换候选/原版」。
- **材料题**：原主档案例不变。`z_case_staging_v31.json` 只添加已能按卡号关联的候选材料，卡片上可查看完整材料及小问。历史真题原卷未逐字核签的材料不得冒充原卷；所有新编材料均以候选来源分层显示。
- **UI 间距**：降低通用按钮最小固有宽度并保留触控高度；部分水平操作行固定间隔；答案标签加截断约束；答案页三个选项卡增加内边距并禁止文本挤压；模拟题元数据改为竖向排布；案例入口按钮补足上下间距；V24模块提供搜索和分页，避免一次绘制378行。

## 三、正常使用与界面

1. 首页点击「437实务 · 生僻名词378题」，进入与2497主库独立的列表；可按 `437M024`、术语或答案搜索、分批显示和进入单张学习。
2. 该模块内可看五维答案、三词提示与来源状态；训练分值与原题分值分别保留。原题骨架不被重写。
3. 真题模拟331永远不会出现 `437M`；真题模拟437的名词解释候选可选取本模块（必须标记为“437专项训练·非原卷”）。
4. 在主库某张卡片点「切换候选/原版」，可以对照Z00—Z08多个来源的候选答案与助记，不会默默更新已有答案或改变原始哈希。
5. 若该卡存在候选材料，可点「查看独立案例候选」阅读材料与小问。来源状态以原包提供的信息为准，不能视为已核签真题。
