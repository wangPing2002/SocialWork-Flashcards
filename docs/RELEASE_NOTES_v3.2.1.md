# 社会工作闪卡 v3.2.1

本版是 v3.2.0 的**界面与答题元信息一致性修复**，不是重新构建题库。

## 用户可见改动

- **历年真题统一入口**：R10 新增真题继续纳入历年真题；移除重复的“新题补录”浏览入口。
- **题面去除汇编序号**：R10 题目前多余的 `1.`、`2.` 等列表序号及内部技术编号不再占用卡片题面；原始题文、来源记录和哈希保持原样。
- **训练分值统一显示**：2497 张主库卡片统一显示建议训练分值与有效字数。建议分值由已有有效字数按 25—30 字/分推算，明确标识“建议”，不是历史原题分值；437专项和 R10 按各卡/各小问的对应训练分值显示。
- **保留原版紧凑切换**：完整解答与快速记忆沿用 RC2 的紧凑交互，不增设大按钮。

## 数据兼容及考试隔离

- 2497 张主库、437 专项 378 题、R10 的 56 条题目记录及 4 份材料主档均保留。
- 原始题文、案例材料、答案正文、助记以及来源证据未被本次展示修复重写。
- 331 模拟组卷不会抽取 V24 437 专项；437 模拟仍依照原有题型和来源隔离规则执行。

## 发布注意事项

- Android 正式版 `versionName = 3.2.1`，建议 `versionCode = 32`（必须高于此前已发布版本）。
- 本次补丁验证包括 `verify_v321_exam_consistency.py`、既有 V3.2/RC2/R10 数据检查、331/437 模拟组卷回归。
- APK 构建通过与否、签名是否一致、旧版覆盖安装是否保留学习进度，需要在 GitHub Actions 与实际设备上核验。
- R10 回忆/汇编来源及 AI 候选答案仍保留证据等级与待核状态，未冒充官方原卷或独立专业签核。
