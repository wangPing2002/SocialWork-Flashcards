# 社会工作闪卡 v3.0：答案与快速记忆精修工程路线图（规划版）

> 制定日期：2026-10-19。文件性质：**待试点验证的项目精修规范**，本文件不代表已对 2497 张卡片完成修订，也不更改现有 APK 运行数据。

## 0. 基线与目标

- 当前 `cards.json` 共 **2497** 张卡片：简答题 1784、论述题 280、名词解释 234、案例分析题 160、材料题 39。
- 当前 `quick_memory.json` 共有 2497 个卡片键值，数据字段均为 `example` 与 `mnemonic`；部分例子与口诀通过复述或拼接答案来增加篇幅，缺乏回忆提示价值。
- 目标：实现 **专业依据可追溯、正式答案可直接上考场、快速记忆可触发重建、修改历史可追踪、Android UI 可用** 的闭环。
- 现存答案与历史审校台账是版本基线；未核对来源前，不得用自动生成内容整体覆盖。

## 1. 学习资料与权威层级

1. **学科与答案事实依据（优先核对）**：项目既定四本核心教材：《社会工作概论》《社会工作实务-250纠正》及《2026年社会工作者〈中级综合〉》上下两部分。
2. **实务类增补参考（已获允许）**：《社会工作实务_理解与答题框架_复核补漏版.docx》，围绕 18 章，特别适合选点规则、个案／小组／社区／社会行政四层介入、具体技巧及情境例子。必须与对应核心教材核对；不可用通用模板替代指定教材分类，也不可推定每案需要四层全部展开。
3. **记忆与笔记加工方法依据**：《高效背书方法论_精华最终版.pdf》：重点采用“基本词—范畴词—提示词”“八变”“提示词前置”“缩写提纯—扩写复原”“闭卷默写／模考”。其建议字数及三色笔记不是项目正式答案的直接覆盖规范。
4. **考察方式辅助依据**：既有东南大学历年真题及其核实过的出处，用于题型模拟、考频与答题侧重点；避免把模拟题标为逐字真题。
5. **外部资料**：主要用于理解例子的启发、事实交叉核实及表达优化；如引入新知识点，必须单独记录出处并经教材兼容性复核。材料冲突应明确标注，不静默替换。

## 2. 题型书写规范

| 题型 | 必备结构 | 既定目标 |
|---|---|---|
| 名词解释 | 定义 → 本质／特征／构成 → 必要的功能、意义或边界；历史事件／人物题可加时间地点背景 | 250–300 字 |
| 简答题 | 简洁总起 → 3–5 个有逻辑的核心点及论证 → 简洁结语 | 500–700 字 |
| 论述题 | 中心判断 → 逻辑分层论证（通常 3 个以上主论点）→ 专业分析、例证或对策 → 总结 | 通常约 900 字，按实际分值调整 |
| 案例分析题 | 证据识别、风险与需要评估 → 理论／方法依据 → 可执行介入行动 → 过程及结果评估 | 按题目与分值 |
| 材料题 | 逐小问作答：引用或概括相关证据 → 专业判断 → 解释或措施 | 按小问分值 |

说明：高分值（例如 ≥50 分）的完整论文式论述题，在实际题目要求适合时才使用“标题—摘要—关键词—分论点—结尾”。不无差别将此模板用于一般论述题。图片示意属于结构参考，不可机械补充无依据的时间／人物／贡献。正式答案仍须符合自然段及规范编号，**只有核心得分句使用 `#C62828` 高亮**；禁止恢复已取消的“30 秒口述版”。

## 3. 快速记忆规范（与正式答案分层）

按复杂程度选择 3–5 个模块，不能为了填模板而增加赘述。

- **答题骨架（framework）**：3–5 个范畴词或逻辑层次，概括答案应写什么、先后关系如何。
- **提示词（cues）**：各要点前置 2–4 字触发词，尽量与得分点对齐；超过 3 个要点时尝试数字式二次压缩。
- **理解例子（example）**：一个具体、生活化、专业上成立的情境，必须能帮助区分概念、理解因果或看到介入技术的实际操作。不得全文重复得分点。
- **口诀／记忆线索（mnemonic，可选）**：只有自然、有辨识度、能触发回忆时才写；禁止把“完整答案→完整答案”的拼接文字伪装成口诀。
- **闭卷回忆（recallQuestions）**：2–4 个结构化提问；先看提示词尝试答题，再核对完整答案，必要时标记遗漏的点。

建议的默认展示顺序：**框架 → 提示词 → 理解例子 → 可选口诀 → 闭卷自测**。对于特别简单的概念，保留框架、提示词和一个例子即可。

### C0597 示范草案（未通过教材逐句核验）

**题目：**主动求助者与非自愿服务对象在接案策略上有何不同？

- **骨架：** 求助动机差异 → 主动者明确需求与目标 → 非自愿者先建立合作关系 → 尊重、自决、安全及法律边界。
- **提示词：** 动机差异／明确目标／先建关系／澄清边界。
- **例子：** 一人主动预约社工帮助，可迅速讨论需要和服务目标；另一人经学校转介且存有疑虑，社工先解释自身角色与服务性质，认真倾听担忧，再探索可合作的问题。
- **记忆线索：** “主动定目标，非愿先关系，共同守边界。”
- **闭卷追问：** 两者为什么策略不同？主动者接案应澄清什么？非自愿者为何不应急于制订计划？两者共有何专业原则？

**示范定位：**这是“学习提示”的样式示例，不是已审核并可直接入库的新答案；答案来源与提取覆盖率须在试点时复核。

## 4. 实务题专项规范

优先采用“**题干证据 → 具体问题／需要 → 介入层次 → 实际技巧 → 实施方式 → 预期目标 → 评估指标**”。

- 情绪困扰可考虑倾听、情感反映等心理支持；只有存在明确认知偏差时才考虑认知矫正，不能把真实制度性不公解释为个人认知错误。
- 技能缺乏要说明示范—模仿—角色扮演—反馈—情境迁移，而不能笼统写“开展培训”。
- 小组工作需要互动、共同需要及交流反馈，**一次讲座不等于小组工作**。
- 社区工作先明确需要解决资源、信息、参与还是服务发现问题，再决定资源链接、信息平台、议事协商、网格服务等措施。
- 社会行政需明确相关机构、分工转介、会商与回访，不能只罗列“完善机制”。
- 存在暴力、危机或即时伤害时先处理保护与安全，严格守住社会工作者角色边界。
- 四层是**可供选择的思考框架**，不是每道题必须写四层；遇到教材指定的分类问法，先忠实回答原分类。

## 6. 阶段路线与发布门禁

### 阶段 A：冻结基线＋规范批准
- 保存不含构建缓存的**独立 ZIP 备份**；结合 Git 分支管理版本；绝不使用 Gradle 备份。
- 运行 `python scripts/verify_repository.py`，记录 2497 张卡片的答案哈希和母版一致性。
- 将本规划拆成正式的答案规范、记忆规范和来源等级文件；用户确认后固定版本。
- 门禁：数据数量、ID、哈希、引用不变。

### 阶段 B：跨题型试点
- 优先抽取约 **25 张**：五种题型每类约 5 张，包含 `C0597` 和多个实务案例，覆盖易混概念、流程、制度、理论与案例选点。
- 分别形成“原答案—新答案—骨架—提示词—例子—自测—依据”的审阅对照，**先不批量写回**。
- 用户验收：能否只看提示词复原得分点？语言是否自然？例子有没有帮助理解？实务技巧是否具体且合适？
- 门禁：五种模板可用，试点不存在重大教材冲突和无依据扩展。

### 阶段 C：更新快速记忆显示
- 改造新记忆模块的 Android 展示：重点突出、低阅读负担、支持折叠自测，保持答案区滚动完整。
- 保留用户跨卡选择“快速记忆／完整解答”的交互习惯。
- 门禁：旧数据可读、长文字不截断、无明显布局错位、打包构建通过。

### 阶段 D：专题和优先级推进
- 按**真题高频、用户薄弱、学科重要性及内容问题严重程度**排序，不仅按卡片编号顺序。
- 实务题以《社会工作实务》教材章节与已授权的 18 章资料形成“领域—典型问题—具体技术—辨析边界”映射。
- 每轮约 50–100 张，质量与回归验证通过后才扩大批次；未复核的材料仍标注待审，不混为已验收。
- 正式答案沿用项目安全写回逻辑，校验旧答案哈希、App 答案、Markdown 母版和台账；快速记忆建立独立审校与写回通道。

### 阶段 E：全库质量验收与发行
- 静态：2497/2497 ID 完整；母版与 App 答案一致；快速记忆覆盖完整；引用有效；答案格式、长度、重点色、来源可追溯。
- 内容：人工重点复核教材一致性、正式答案得分点、记忆提示召回效果、案例与专业伦理边界；自动检测只生成待复核提示，不能代替专业审阅。
- 运行：GitHub Actions / Gradle **只用于 APK 编译**，不作为备份工具；实机检查答案/快速记忆切换、折叠、滚动、长答案显示与数据迁移。
- 发布：每批保留独立 ZIP 快照、Git 提交、批次记录与回滚路径。

## 7. 版本纪律

- **规划阶段不修改题库**；试点成果用户确认后才写入正式数据。
- **严禁**把历史 Round 审校脚本作为新的自动覆盖入口，严禁使用不带旧哈希的全库重写。
- 将“记忆方法是否对学习者有效”纳入人工反馈，不将机械压缩率视为唯一优劣指标。
- 每次只发布经过审查的增量；对未完成或存疑的卡片，保留“待核查”的明确状态。
