# V3.2.1 候选补丁：真题入口、序号和训练分值一致性修复

## 不修改的事实材料
- 2497 张主库：ID、题干、完整答案、助记数据和历史分值来源保持不变；`cards.json` 原文件不修改。
- 437 专项378张：保持 `v24_437_378_cards.json` 不变，仍然仅进入437题源。
- Z00 R10：56条题目记录、4份材料题组、10份独立小问；原始 `question`、`sourceQuestionOriginal`、SHA-256、证据等级、答题正文不变。

## UI 修正
1. 卡片库保留「历年真题 / 真题关联 / 教材框架」三个入口，取消冗余「新题补录」。既有真题与R10仍合并在「历年真题」中，保证原题不因入口取消而丢失。
2. R10题面展示时移除汇编材料中开头明显的排版编号，如「3. 社会福利三分法」展示为「社会福利三分法」；*原始题文不修改*。R10内部数据库ID保留，但不会作为学习卡片标题和真题列表的视觉前缀。
3. 完整解答均按「训练分值：… · 有效字：…」展示。主库2497张过去缺少训练分值：本补丁以每卡既存 `answerEffectiveChars` 和 SOP 的每分25–30有效字估算一份**建议训练分值**，存放在独立只读资源 `training_score_suggestions_v321.json`，界面标明「（建议）」；不能视为用户核签分值、历史真题实际分值或校方标准分值。
4. V24专项原有10分训练分值不变；R10现有训练分值属于AI候选，界面同样标注「（建议）」。材料题组不虚构整题分值，10份小问在揭晓解析时独立显示训练分值与有效字。
5. 「快速记忆」区域仍不显示训练分值、有效字或完整答案正文，保留 RC2 原版紧凑切换。

## 标注算法
选择最接近 `有效字 / 27.5` 的整数训练分值，同时严格限制于 `ceil(有效字/30) <= 训练分值 <= floor(有效字/25)`。算法得到的分值只用于备考训练安排，后续逐题专业校准可更新映射而不必改动原题和答案。
