# 社会工作闪卡 v3.2.0

本版本在 v3.2 RC2 基础上整合 Z00 R10 真题补录，并精简运行界面和工程结构。

## 功能更新

- 普通题库保留 **2497 张卡片**；437 实务生僻名词解释独立专项保留 **378 张卡片**。
- 继续采用紧凑的“完整解答 / 快速记忆”切换方式，避免大按钮占用学习空间；学习首页移除与卡片库重复的入口。
- 437 专项卡片标题展示术语本身，不重复显示固定的“名词解释：”前缀。
- 新增 Z00 R10 真题补录数据源：**56 条可辨认题目记录**、**4 个复合题组**、**10 条案例小问**，对应 **62 个独立答案单位**；保留 7 个空题位与 1 条考点回忆，均不冒充完整原题。
- 保持 331 社会工作原理与 437 社会工作实务模拟组卷题源隔离；2024 年两份仅有摘要材料的案例不进入自动模拟组卷。
- 整理历史安装残留与可再生测试报告，不删除原始题目、审校台账和必要证据文件。

## 资料准确性说明

Z00 R10 新增真题来源属于汇编／回忆资料，尚未完成官方原卷逐字核签。新增完整解答为基于交接资料整理的 **候选答案**，不宣称已获独立专家审核。材料摘要不代表真实原卷全文。请结合题目证据等级使用。

## 更新建议

建议升级前使用应用内备份功能保存学习数据。**不要卸载旧版或清除应用数据**作为升级步骤。正式发布前应通过 CI 签名 APK 构建、签名校验与实际设备升级测试。
