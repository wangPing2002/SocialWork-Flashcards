# 1. 项目简介

“社会工作闪卡”不是把大段答案简单搬进手机，而是围绕主动回忆建立完整学习闭环：

> **学习 → 主动回忆 → 揭晓答案 → 熟悉度判断 → 间隔复习 → 弱卡优先 → 内容纠错 → 题库修订**

项目主要面向社会工作考研复习，同时兼顾日常知识整理与碎片化复习。

### 核心特点

- Android 原生离线应用；
- 不需要账号，学习数据默认保存在本机；
- 每日学习量统一管理；
- 支持未完成会话继续学习；
- 复习只从已经学习过的卡片中产生；
- 最近 10 次学习结果参与弱卡排序和熟练度判定；
- 长答案、例子、真题信息按需展开；
- 支持模糊搜索、多关键词和有限同义词映射；
- 支持收藏、本地修正、内容反馈；
- 支持完整备份与恢复；
- 正式版使用固定 Release 签名，支持长期覆盖升级。

# 2. V2.8.4 亮点

V2.8.4 重点解决实际刷题路径：从专题卡片进入学习后，返回会回到原专题/小库，不再直接跳首页；相关知识点改为全屏覆盖学习，关闭后原学习序列保持不变。

## 2.1 三条学习路径

- **真题题库**：集中历年真题与回忆主题；
- **真题关联知识点**：从真题卡的 `relatedIds` 自动汇总，去除真题本身并按关联真题数量优先排序；
- **教材系统题库**：保留 2497 张完整母版卡片与 14 个一级、73 个二级专题。

## 2.2 板块连续学习与返回路径

- 从一级专题、二级专题、真题题库或关联知识点库进入学习，会保存来源页面；
- 点击某张卡后从该卡继续向后刷，不再只生成单卡会话；
- 中途返回或完成本轮后，可回到原板块；
- 相关知识点使用覆盖式阅读/评价，不覆盖主学习队列。

## 2.3 稳定性优化

搜索结果与独立小库采用分批渲染，每次最多创建 60 个卡片视图，避免常见词搜索一次性生成上千个 View 导致内存压力或界面闪退。

## 2.4 教材框架试点

根据教材式思维导图，新增“社会工作服务”框架试点，按 **要素 → 目标 → 功能** 展示知识树，并可直接进入 C0011—C0033 的连续学习序列。

# 3. 核心功能

## 3.1 学习

- 每日学习量；
- 开始今日学习；
- 中断后继续学习；
- 固定卡片视口；
- 卡片内部滚动；
- 问题页纯回忆；
- 答案页熟悉度评价；
- 最近 10 次表现；
- 例子与完整答案；
- 真题考频与已核验参考答案；
- 相关知识点预览；
- 331 / 437 真题结构智能模拟组卷；
- 逐题考频手动调整与熟练度自动显示。

## 3.2 卡片库

卡片库采用两级专题浏览：

- 五个展示组：核心知识 / 专业方法 / 专业体系 / 实务领域 / 综合训练；
- 14 个一级专题；
- 73 个二级专题；
- 一级专题页显示总卡数、已学习数和学习进度；
- 二级专题页显示该专题下的实际卡片列表；
- 全部 / 已学习 / 未学习 / 收藏筛选继续保留；
- 多关键词搜索，例如：`危机 介入 原则`；
- 搜索同时覆盖题目、一级专题、二级专题、答案、出处等字段；
- 部分词匹配，例如：`社会支` → `社会支持`；
- 有限专业同义词映射，例如：赋能 ↔ 增权、危机干预 ↔ 危机介入、临终关怀 ↔ 安宁疗护、REBT ↔ 理性情绪治疗、韧性 ↔ 抗逆力；
- 按相关度排序并显示命中来源。

> 搜索不会进行激进的错别字猜测，以免考研题库出现错误关联。

# 4. 学习与复习机制

## 4.1 每日学习量统一

项目不再把“每日新学量”和“每日复习量”拆成两个设置，统一为：

> **每日学习量**

例如设置为 30 张：

- 当天未完成目标时，系统生成剩余学习队列；
- 当天目标完成后仍可继续加练；
- “继续学习”从上次中断位置恢复，不重新抽卡。

## 4.2 学习与复习边界

严格遵守：

> **复习只能从已经学习过的卡片中产生。**

未学习卡不会被当作“复习卡”。

已经学习的卡可以：

- 重复出现；
- 根据薄弱程度增加出现概率；
- 在达到复习时机后优先进入队列。

## 4.3 最近 10 次与弱卡优先

每张卡保存最近 10 次评价：

- 熟悉；
- 不清楚。

排序综合考虑：

1. 是否已经学习；
2. 是否达到复习时间；
3. 最近 10 次“不清楚”比例；
4. 最近连续“不清楚”次数；
5. 距离复习到期时间。

目标行为：

- 一般卡通常出现 1 次；
- 中度薄弱卡可重复约 2 次；
- 高度薄弱卡可重复约 3 次；
- 尽量避免同一卡片连续出现。

## 4.4 间隔复习

基础间隔参考：

```text
10 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天
→ 7 天 → 15 天 → 30 天 → 60 天
```

实际优先级还会结合最近 10 次表现，因此不是机械按固定时间排序。

# 5. 题库与内容准确性

## 5.1 当前规模

当前安装包内包含：

```text
C0001—C2497，共 2497 张卡片
5 类正式题型：名词解释 / 简答题 / 论述题 / 案例分析题 / 材料题
逐卡完整标准答案
逐卡预测考频、真题标注、来源、答案状态与关联问题
```

主要覆盖：

- 社会工作原理；
- 社会工作实务；
- 个案工作；
- 小组工作；
- 社区工作；
- 社会工作督导与服务管理；
- 医务、学校、司法、防灾等实务领域；
- 企业社会工作；
- 基层治理；
- 退役军人事务社会工作；
- 新就业群体社会工作；
- 社会心理视角、诊断学派等理论内容。

## 5.2 资料使用原则

题型、考试结构、答案组织方式与考点权重主要参考：

- 王思斌《社会工作概论》（第 4 版）相关资料；
- 东南大学社会工作考研真题 2015—2026。

事实性内容优先使用教材与可核验资料，不把真题汇编或 OCR 文本作为唯一事实来源。

资料发生冲突时：

- 不静默拼接成一个“看似完整”的答案；
- 保留教材 / 考试框架的明确口径；
- 必要时标注差异；
- 无法确认时宁可暂缓发布。

## 5.3 正式卡片最低标准

正式卡片应满足：

- 问法自然，接近教材习题或真实考试；
- 核心答案能够被来源支持；
- 例子不改变理论边界；
- 扩展理解不伪装成教材原文；
- 真题年份、科目、题型不猜测；
- OCR 不清、来源不完整的内容不作为确定事实发布。

## 5.4 真题发布规则

真题信息区遵循：

- 只有年份明确、题干明确、专题对应明确的记录进入主考频；
- 2024 / 2025 等仅依据汇编顺序推定年份的记录单独标注，不计入主考频；
- “未发现直接命题”不等于“低频”或“不重要”；
- 未通过核验的真题显示“答案待核验”；
- 不用相关专题的泛化答案冒充某一道具体真题的答案。

# 6. 内容纠错与本地修正

App 支持在不修改正式题库文件的情况下保存本地修正。

## 6.1 内容反馈

可标记：

- 概念或答案错误；
- 答案不完整；
- 题目表述不准确；
- 真题信息有误；
- 出处 / 章节有误；
- 例子或扩展答案有误；
- 知识点重复或冲突；
- 其他。

## 6.2 本地修正

可修改：

- 题目；
- 答案要点；
- 记忆提示；
- 出处；
- 例子；
- 名词解释完整答案；
- 简答完整答案；
- 论述 / 案例完整答案。

本地覆盖保存在：

```text
content_feedback.db
```

不会直接修改安装包内的：

```text
cards.json
details.json
```

## 6.3 反馈闭环

标准修订流程：

1. 在 App 中标记或本地修正；
2. 导出内容反馈 JSON；
3. 上传反馈文件；
4. 回到教材 / 真题重新核验；
5. 更新正式题库；
6. 在 README 版本记录中注明修订；
7. 发布下一版本。

核心原则：

> **宁可少一张卡，也不要多一张不可靠的卡。**

# 12. README 维护规则

`README.md` 是项目唯一的主要说明文档。

以后**不要再新增**：

```text
CHANGELOG_Vx.x.md
CONTENT_ACCURACY_NEW.md
RELEASE_SIGNING_NEW.md
PROJECT_STRUCTURE_NEW.md
NEW_CARDS_xxx.md
```

新版本发布时：

1. 更新 README 顶部版本号与项目状态；
2. 如果功能 / 数据 / 签名 / 内容规范发生变化，同步修改对应正式章节；
3. 在“版本更新记录”中追加该版本；
4. 保留旧版本记录，不重复在 README 开头堆放版本说明。

目标是：

> **README 顶部永远描述当前真实状态，底部版本记录负责保存历史。**
